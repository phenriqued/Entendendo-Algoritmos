# Estruturas de Dados e Algoritmos em Java.

Este roadmap foi elaborado para ajudar nos estudos de **Estruturas de Dados e Algoritmos (DSA)** utilizando Java, seguindo como base principal o livro ["Entendendo Algoritmos" de Aditya Bhargava](https://www.amazon.com.br/Entendendo-Algoritmos-Ilustrado-Programadores-Curiosos/dp/8575225634). 

Aqui você encontrará implementações feitas do zero, análises de complexidade e soluções organizadas por módulos — refletindo uma abordagem profissional e orientada a portfólio.

## 🎯 Objetivos do Projeto
* Estudar algoritmos de forma estruturada.
* Desenvolver raciocínio lógico e pensamento computaciona.
* Implementar estruturas de dados "na unha" para entender seu funcionamento interno.
* Manter organização profissional no GitHub.

## 📘 Estrutura do Repositório
A estrutura utiliza um único projeto Java, dividido em pacotes. Cada pacote representa um capítulo ou conjunto de conceitos estudados.
* EntendendoAlgoritmos/
    * 📁 src/main/java/
        * cap01_Busca_Binaria/
        * cap02_Vetores_Listas_e_Ordenacao_Selecao/
        * cap03_Recursao_e_Pilhas/
        * cap04_Dividir_Conquistar_Quicksort/
        * cap05_Tabela_Hash/
        * cap06_Grafos_Pesquisa_Largura/
        * cap07_Algoritmo_Dijkstra
        * cap08_Algoritmos_Gulosos
        * cap09_Programacao_Dinamica
        * extra_Outros_Algoritmos_Ordenacao/


### 📦 Estrutura Interna de Cada Pacote
Cada pacote pode conter:
* Uma classe Main explicando o conceito e desenvolvendo os problemas para execução da solução
* Classe com exercícios resolvidos
* Testes (quando aplicável)

## 📘 Roadmap de Estudos

Abaixo está a progressão de estudos baseada no livro:

🔹 Capítulo 1 – Busca Binária
* Busca binária iterativa
* Busca binária recursiva
* Análise de complexidade O(log n)

🔹 Capítulo 2 – Ordenação por Seleção
* Vetores e Listas
* Selection Sort
* Comparação com outros algoritmos

🔹 Capítulo 3 – Recursão e Estruturas Lineares
* Pilhas
* Recursão

🔹 Capítulo 4 – Dividir para Conquistar
* Quicksort
* Merge Sort
* Estratégia de divisão e conquista

🔹 Capítulo 5 – Tabelas Hash
* Conceito de hashing
* Tratamento de colisões

🔹 Capítulo 6 – Grafos e Busca em Largura (BFS)
* Representação de grafos
* Busca em largura
* Menor caminho em grafos não ponderados

🔹 Capítulo 7 – Algoritmo de Dijkstra
* Grafos ponderados
* Caminho mínimo

🔹 Capítulo 8 – Algoritmos Gulosos
* Estratégias locais
* Problemas de otimização

🔹 Capítulo 9 – Programação Dinâmica
* Subproblemas
* Tabelas de memorização
* Problema da mochila
* LCS
  
🔹 Capítulo 11 – Algoritmos Avançados e Complexos
* Árvore Binária de Busca
  
📌 Observações Importantes
* Sempre que possível, as estruturas são implementadas do zero antes de usar as classes prontas do Java.
* Se você é recrutador ou desenvolvedor, fique à vontade para explorar o repositório ou trocar uma ideia.
