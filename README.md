# Estruturas de Dados e Algoritmos em Java.

Este roadmap foi elaborado para ajudar nos estudos de **Estruturas de Dados e Algoritmos** utilizando Java, seguindo de perto os capítulos do livro ["Entendendo Algoritmos" de Aditya Bhargava](https://www.amazon.com.br/Entendendo-Algoritmos-Ilustrado-Programadores-Curiosos/dp/8575225634). 
O objetivo é evoluir do iniciante ao avançado com exercícios.

A estrutura é utilizar um único projeto Java com vários pacotes, onde cada pacote representa um capítulo, módulo ou conjunto de exercícios.

## 📘 Estrutura do Repositório:
* EntendendoAlgoritmos/
    * 📁 src/main/java/
        * cap01_Busca_Binaria/
        * cap02_Vetores_Listas_e_Ordenacao_Selecao/
        * cap03_Recursao_e_Pilhas/
        * cap04_Dividir_Conquistar_Quicksort/
        * cap05_Tabela_Hash/
        * cap06_Grafos_Pesquisa_Largura/
        * extra_Outros_Algoritmos_Ordenacao/

\
\
Cada pacote contém:
* Uma classe Main explicando o conceito e desenvolvendo os problemas para execução da solução
* Classe com exercícios resolvidos
* Classes de teste
